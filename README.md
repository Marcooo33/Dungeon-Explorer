# Dungeon-Explorer
Dungeon Explorer is a videogame developed for the course of "Operating Systems Lab" of the Università degli studi Federico II

# Prerequisites
You must have the `docker engine` installed on your machine and have installed the executable for the client (aviable under the [releases](https://github.com/Marcooo33/Dungeon-Explorer/releases) tab).

# Instructions on starting up the project
In order to start-up the project you have to follow the following steps:
1. Clone this project.
2. While being in the root of the project type in the terminal the following command: `docker compose up server-prod`.
3. Execute the client.
4. Enjoy yourself! :).
